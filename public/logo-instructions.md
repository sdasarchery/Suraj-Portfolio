# Logo Placeholder

This is a placeholder for your logo. 

## How to add your logo:

1. **Place your logo image** in the `public` folder as `logo.png`
2. **Supported formats**: PNG, JPG, SVG, WebP
3. **Recommended size**: 40x40 pixels (or larger, it will be resized)
4. **File name**: Should be exactly `logo.png` (or update the src in Layout.js)

## Alternative logo names you can use:
- `logo.png`
- `logo.jpg` 
- `logo.svg`
- `suraj-logo.png`

Just make sure to update the `src` path in Layout.js to match your file name.

## Current logo settings:
- Width: 40px
- Height: 40px
- Border radius: 4px (slightly rounded corners)
- Location: Top navigation, links to home page

You can modify these settings in `components/Layout.js` if needed.
